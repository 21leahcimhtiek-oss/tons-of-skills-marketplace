Frequently Asked Questions

What is a Claude Code plugin marketplace?

A Claude Code plugin marketplace is a centralized registry of plugins, skills, agents, and hooks that extend Claude Code's capabilities. Instead of searching GitHub for individual repos, you browse a curated catalog and install with one command.

How do I install plugins from Tons of Skills?

Use the CLI command /plugin install pluginname@claude-code-plugins-plus directly in Claude Code, or use the ccpi npm package for batch installs and management.

Is Tons of Skills free?

Yes, 100% free and open source under the MIT license. All 440 catalog plugins and 3,018 marketplace-visible skills are available at no cost. The entire codebase is on GitHub.

How is this different from awesome-claude-code lists?

Awesome lists are curated link collections — useful for discovery but with no install tooling, search, or validation. Tons of Skills is a full marketplace with a searchable web UI, CLI installer, quality validation, structured metadata, and dedicated plugin pages.

Can I contribute my own plugin?

Absolutely. Fork the repo, add your plugin to the appropriate category, and open a PR. Our CI pipeline validates structure, metadata, and security automatically. See the Contributing Guide.

What are Agent Skills vs Plugins?

Plugins are packages containing instructions, commands, and configurations. Skills (SKILL.md files) are auto-activating capabilities within plugins — they trigger based on context without needing a slash command. A single plugin can contain multiple skills.

CLI Tools

Professional command-line tools for managing Claude Code plugins. Diagnose issues, monitor usage, and stay connected to your AI workflows.

CCPI Doctor

Available now

Comprehensive system diagnostics for your Claude Code installation. Verify plugins, check dependencies, and ensure everything is configured correctly.

  • Detect Claude Code installation paths (Linux, macOS, Windows)
  • Verify Node.js and package manager versions
  • Check installed plugins and marketplace status
  • Validate plugin configurations
  • Generate detailed diagnostic reports (JSON output available)
npx @claude-code-plugins/ccp doctor

Quick Start

1

Add the Marketplace

Open Claude Code and run: /plugin marketplace add jeremylongshore/claude-code-plugins

2

Install CLI Tools

The @claude-code-plugins/ccp package is published to npm. No installation needed - just use npx!

3

Run Diagnostics

Verify your setup with: npx @claude-code-plugins/ccp doctor

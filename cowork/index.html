How to Install

Four steps inside the Cowork desktop app. No terminal required.

01

Download

Click any download button above. Your browser will save a .zip file to your Downloads folder.

02

Unzip

Double-click the .zip file to extract it. Keep the unzipped folder somewhere you can find it.

03

Open Cowork → Customize

In the Claude desktop app, switch to the Cowork tab, then click Customize in the left sidebar and choose Browse plugins. Use the upload-a-custom-plugin option to add your unzipped folder. See Use plugins in Claude Cowork for the canonical walkthrough.

04

Restart if prompted

The plugin's skills, agents, and commands appear in your Cowork workspace once installed.
